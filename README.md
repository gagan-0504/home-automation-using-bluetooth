This project is about home automation using bluetooth connection by arduino uno.
There is an apk file where it is for an app made using mit app inventor to control and command the arduino to control the electrical components,
the diagram is of the arduino and the connections made with components(There is only one component a 5v fan but we can add more components with reference to the app and code),
there is also an .txt file containing code for the arduino uno. 
Guide:
First we have to set up the connection as per the components in the app and at their arduino ports itself.
Connect the bluetooth(HC-05) to arduino .
Write the code the arduino,compile and upload to it.
Connect the bluetooth to arduino.
Once connected open the app.
The app reads connected and shows the components and let's you control the components.
This is all about the project(Home automation using bluetooth and arduino).
